# White Label Guide

To rebrand for a new company:

1. Set company defaults in `.env`.
2. Run first-run setup.
3. Log in as owner admin.
4. Open Admin > Setup Panel.
5. Update Website: title, tagline, logo, colours, typography, homepage copy, contact details.
6. Update ERP Platform: platform title, sidebar brand, internal logo, labels and colours.
7. Update System: agency profile, currency, shared file root.
8. Create staff users.
9. Add real properties, tenants, CRM contacts and documents.

Avoid:

- Shipping client data in source.
- Committing uploaded files.
- Hardcoding domains or emails in code.
- Leaving temporary admin passwords.
